本规范的主要作用
1、用于大型项目开发， 将项目需要的功能和要求以文件的形式创建出来，脱离ai的胡思乱想。
2、共有三个模块
  模块一：调研，通过和用户沟通明确需求，
  模块二：开发经验模版，根据需求和项目中的编程开发规范，如前端开发规、后端开发规范、数据库设计规范等，开发中使用的优秀的项目经验案例模版。
  模块三：规范的自我进化 规范需要不断的优化，完善覆盖开发范围

 使用：
 1、首先通过一句话 指定ai 通读和加载 规范的 总则，理解怎么和用户沟通，以及用户的需求怎么处理。
 2、项目开发，基本覆盖开发过程中的项目设计 、bug 修改 等等
 3、开发过程 按需加载需要的参考文件，拒绝ai 自我胡想，同时改动留痕。避免新会话 记忆问题。
